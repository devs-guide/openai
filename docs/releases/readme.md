# DOT releases

Public release notes use `docs/releases/<version>.md` and are also used as the
reviewed GitHub release body.

- `0.0.1.md` — published immutable baseline: initial DOT source,
  documentation, publication, and release contract.
- `0.0.2.md` — candidate two-lane Agent and four-stage Research consolidation,
  tagged-archive ingestion, structured release lifecycle, migration audit, and
  compatibility routes.

Tags use bare semantic versions. Published tags are immutable; corrections use
a later version. Compatible corrections and clarifications accumulate in the
current patch series; the next minor series is reserved for a separately
approved contract-maturity milestone. Editorial-only changes are batched
rather than released alone.
