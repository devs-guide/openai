DOT Agent

#AGENT is the stable operating lane for DOT. It defines the runtime, permissions, models, browser, storage, Pages, tools, and media behavior that a project may use. It does not define a research topic or contain research findings.

Read left to right

master.prompt → config.json → runtime.json → capability module

Capability module Use
browser.prompt #BROWSER, configured #TABS, #CAPTCHA, and browser-based #TOOL behavior
page.prompt #PAGE, saving, delivery, and readback verification
media.prompt #VIDEO, captions, audio, and #TRANSCRIPTION

Load only the capability modules needed by the active project. A project may narrow this lane but may not silently expand its permissions, models, tools, accounts, or destinations.

#TABS is not a separate capability module. It is the Browser-owned shared capacity and recovery configuration in config.json; its canonical rules live inside browser.prompt and apply whenever that module is loaded.
