0.0.1

DOT becomes the first published product in the devs-guide/openai hub. This release curates the original local research prompts and agent operating guides into a stable product hierarchy, records their import provenance, and adds a deterministic documentation and release workflow.

The release separates public prompt products from private lifecycle planning. Every public artifact has an extensionless documentation route and a byte-exact raw download tied to the same repository commit.

Scope

  • Initial release range: repository creation through the accepted 0.0.1 commit.
  • Public product: dot/.
  • Public documentation root: https://devs-guide.github.io/openai/.
  • DOT documentation root: https://devs-guide.github.io/openai/dot/.
  • Source and documentation only; no binary runtime or hosted application.

Highlights

  • Establishes an expandable OpenAI product hub with DOT as the first product.
  • Publishes one current master prompt, retained reference variants, reusable research starters, and dated agent operating guides.
  • Preserves original SHA-256 provenance while normalizing public paths.
  • Generates accessible, extensionless documentation and byte-exact raw-source downloads from one reviewed manifest.
  • Validates repository hygiene, source imports, generated links, Pages source identity, and release metadata.
  • Keeps lifecycle context, plans, reviews, and operational evidence in the separate private devs-guide/prompts repository.

Added

  • Root and DOT indexes connecting products, prompts, agents, features, history, and releases.
  • dot/prompts/core/ for the current master and retained core variants.
  • dot/prompts/research/ for reusable research starters.
  • dot/agents/ for browser, computer, document, and prompt operating guides.
  • An initial-import ledger with every original path, normalized path, digest, and disposition.
  • A JSON publication manifest, deterministic static builder, local validators, GitHub Actions, and remote Pages verification.
  • An explicit copyright and no-license notice plus an unofficial-project disclaimer.

Changed

  • Replaced flat source names and colon-bearing agent filenames with stable, lowercase product/project paths.
  • Classified public artifacts as current, reference, reusable template, or dated evidence without rewriting their imported bodies.
  • Separated rendered documentation routes from exact raw source routes.
  • Established bare semantic tags and draft-first, human-reviewed GitHub releases.

Fixed

  • Removed the redundant public copy of the byte-identical master prompt while retaining both original identities in the import record.
  • Prevented private lifecycle prompts, local symlinks, generated Pages output, credentials, and operating-system metadata from entering release source.
  • Added commit markers and remote checks so a successful Actions build cannot be mistaken for a matching live Pages deployment.

Safety and publication model

The project is community maintained and is not affiliated with or endorsed by OpenAI. Dated capability observations remain bounded to their documented test windows, while owner policies remain instructions rather than platform facts.

The public repository grants no open-source license. Generated output is built from the reviewed manifest, deployed only from main to an orphan www branch, and checked against the exact source commit. Published tags are immutable; corrections use a later release.

Compilation, builds, and tests run only in GitHub Actions. The local workstation is not a validation environment.
