0.0.3

DOT adds a conditional #SUMMARY contract for creating one standalone, reader-focused executive brief from an existing Research project and its controlled #FACT records. The core #PROJECT → #INTERNET → #DATA → #TEMPLATE workflow remains unchanged.

Scope

  • Public product: dot/.
  • Prior release: immutable tag 0.0.2.
  • Current Research source: dot/research/.
  • Documentation root: https://devs-guide.github.io/openai/dot/.
  • Source and documentation only; generated research PDFs are runtime deliverables and are not repository or GitHub release assets.

Highlights

  • Adds an on-demand subtopic executive brief without making Summary a required Research stage.
  • Binds material prose, charts, tables, calculations, and estimates to controlled Facts and evidence links.
  • Requires the essential supporting numbers, definitions, and source notes to appear inside the PDF.
  • Defines an engaging education/editorial style that remains evidence-led, accessible, and free of hype or implied organizational affiliation.
  • Requires native PDF delivery, visual inspection of every page, and readback.

Added

  • dot/research/summary.prompt with SUMMARY-001 through SUMMARY-010.
  • A conditional Summary entry in the tagged-release ingestion manifest.
  • An Executive Brief Request and Completion Receipt in the Template contract.
  • Project controls for explicitly activated derivative deliverables.
  • Rendered and raw Pages routes for the Summary contract.
  • GitHub validation for Summary ownership, activation, request fields, evidence-class mapping, rendering boundaries, and publication routes.

Changed

  • Extended Research navigation with Summary as an optional deliverable while retaining the four-stage Project → Internet → Data → Template sequence.
  • Advanced the candidate ingestion and publication identity to 0.0.3 while preserving 0.0.1 as the migration baseline and 0.0.2 as the immediate prior release.
  • Extended feature and release indexes with the executive-brief lifecycle.

Fixed

  • Prevented derived briefs from silently overwriting the main report or an accepted dataset release.
  • Reconciled reader-facing Observed, Calculated, Estimated, and Unavailable labels with the existing derivation, verification, and null-reason model.
  • Prevented links, dashboards, or external spreadsheets from substituting for evidence that must be readable inside a delivered brief.
  • Required unavailable rendering or native-attachment routes to block delivery instead of producing a false completion claim.

Safety and publication model

The project remains community maintained and is not affiliated with or endorsed by OpenAI. Summary does not authorize new research scope, tools, accounts, destinations, contact with third parties, or external sharing.

The browser-first Agent boundary remains unchanged. Codex, software installation, coding projects, local-computer execution, unassigned models, and access-control bypasses remain prohibited by the distributed contract. Privacy and suppression rules override the desire for a self-contained appendix.

Compilation, contract auditing, site builds, and tests run only in GitHub Actions. The local workstation is not a validation environment.
