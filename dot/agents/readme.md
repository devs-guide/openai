# DOT agent guides

These documents record bounded operating contracts, tests, and review material
for browser-, computer-, document-, and prompt-oriented agent work.

- [`browser.md`](browser.md) — browser-first operating guide and verification
  record.
- [`computer.md`](computer.md) — source, browser, evidence, and cleanup test
  procedures.
- [`doc.md`](doc.md) — technical execution contract and task-state model.
- [`prompt.md`](prompt.md) — functional browser test and reporting prompt.

Each guide carries its own evidence labels and dates. A recorded result does not
establish current access, capability, performance, or authorization in another
environment.
